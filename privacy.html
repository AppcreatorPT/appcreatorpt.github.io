Privacy Policy

Last updated: October 30, 2026.

"Estudio" is a private tool used only by the owner of The Real Price to publish videos to the owner's own YouTube channel and Facebook Page. It is not offered to the public.

What the tool accesses

  • YouTube upload (youtube.upload): to upload videos to the owner's channel.
  • YouTube Analytics (yt-analytics.readonly): to read view counts and watch time of the owner's own videos.

What we do with data

Data is used only to publish the owner's videos and to measure how they perform. We do not sell, share or transfer data to anyone. We do not collect data about viewers or other people.

Storage

Access credentials are stored as private secrets of the tool and are never published. Video statistics are kept in the owner's private records.

Google API Services

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

YouTube API Services

Estudio uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

Data deletion

We keep only the statistics of the owner's own videos (views, watch time, subscribers gained). Data received from YouTube API Services is refreshed or deleted within 30 days. If access is revoked, we stop all API calls and delete stored API data within 7 days. To request deletion, contact us (below).

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
